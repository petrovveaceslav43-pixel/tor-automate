# Tor Automate Engine

Automated Tor node management engine with multi-location routing, port mapping, persistence and Xray integration.

---

## Features

- 🌍 Multi-country Tor exit nodes
- 🚀 Automated deployment
- 🔀 SOCKS5 port forwarding
- 📡 Xray integration
- 💾 Persistent node configuration
- 📊 Active node monitoring
- ⚡ Bulk deployment
- 🛠 Interactive CLI interface

---

## Requirements

- Ubuntu 22+
- Debian 11+
- Root access

---

## Installation

```bash
bash install.sh
```
