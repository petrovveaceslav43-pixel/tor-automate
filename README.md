# Tor Automate Engine

Automated Tor node management engine with multi-location routing, port mapping, persistence and Xray integration.
<img width="520" height="520" alt="d1b29bbe-b6b8-4b61-86bb-21be1ce1e6fe" src="https://github.com/user-attachments/assets/b6682e94-8b32-4e24-9e5b-bfa4495826e8" />

---

## Features

- 🌍 Multi-country Tor exit nodes
- 🚀 Automated deployment
- 🔀 SOCKS5 port forwarding
- 📡 Xray integration
- 💾 Persistent node configuration
- 📊 Active node monitoring
- ⚡ Bulk deployment
- 🛠 Interactive CLI interface

---

## Requirements

- Ubuntu 22+
- Debian 11+
- Root access

---

## Installation

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/petrovveaceslav43-pixel/tor-automate/main/install.sh)
```
## Run

```bash
tor-automate
```
